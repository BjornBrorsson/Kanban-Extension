## Summary
Bootstrap the initial Agentic Kanban VS Code / Codium extension architecture, TypeScript services, glassmorphic Webview UI, drag-and-drop file mover, real-time filesystem watcher, and VSIX packaging pipeline.

## Description
Create the foundational components of the extension:
1. `src/ticketParser.ts`: Table, YAML frontmatter, and raw markdown heuristics parser.
2. `src/boardDiscovery.ts`: Dynamic multi-board discovery for any `Tickets/` folder in the workspace.
3. `src/boardManager.ts`: File rename operations, subfolder moves, status syncing, and `FileSystemWatcher` debouncing.
4. `src/agentRunner.ts`: CLI terminal execution and IDE GUI chat command triggering.
5. `src/webview/`: Glassmorphic Kanban view and multi-board overview dashboard.
6. Build and `.vsix` packaging workflow.

## Acceptance Criteria
- [x] TypeScript architecture and esbuild bundling established.
- [x] Multi-board discovery scans workspace and maps top-level folders to columns and subfolders to filter chips.
- [x] Interactive HTML5 drag-and-drop moves files on disk via `vscode.workspace.fs.rename`.
- [x] `Whatwhy.md` files render as column tooltips and guidance instead of ticket cards.
- [x] `config.md` parsed for humans and CLI/GUI code agents.
- [x] Workspace overview dashboard created with parallel work feed.
- [x] Packageable into `.vsix` for direct installation in VS Code, Antigravity, Cursor, and Codium.
